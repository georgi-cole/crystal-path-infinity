# Crystal Path: Infinity store media

English portrait series, revised 10 November 2026. The numbered files use the same order on both stores.

| Panel | Actual game capture |
| --- | --- |
| 01 · The abyss awaits | Main home hub with Play, Practice, and navigation |
| 02 · Two tiles. One choice. | First row of the Classic bridge with both tile choices |
| 03 · Meet Pawrachute | The companion on the rooftop bridge during a crossing |
| 04 · Break the seal | An opened mystery box with the Soul Exchange pact choices |
| 05 · Outrun the clock | The active death clock at six seconds and its warning on the bridge |
| 06 · Six worlds. One Vault. | The actual world catalog with Rockmallow, Flipzel, and Explore controls |

The [Google Play set](google-play) includes six 1080 × 1920 screenshots, a 512px listing icon and a 1024 × 500 feature graphic. The [App Store set](app-store) includes six 1206 × 2622 screenshots for Apple's medium iPhone display slot. The listing and native launcher icons feature Pawrachute jumping over the glass bridge. The Play banner shows the mint and orchid bridge choice.

The panels frame captures from the player UI on the game tree merged by PR #104, at a portrait mobile viewport. A local preview wallet equips Pawrachute for the rooftop capture. The lettering, frames, and lighting around the captures are marketing artwork. The mystery, timer, and Vault panels crop to the relevant in-game controls. The Vault panel shows world exploration without a checkout. These are store design assets. The signed 1.0.0 (43) packages predate the launcher change, so the final store package still needs a fresh build and a device check with the chosen icon.

The English drafts in Google Play Console and App Store Connect contain the six panels in order. The Play draft also contains the Pawrachute icon and feature graphic. Apple takes the installed icon from the selected signed build.
