# Crystal Path: Infinity — Mobile

Самостоятелна игра за Android и iOS, извлечена от Crystal Path: Infinity в The Big Eye.

**Етап: инспекция и подготовка за разработка.** Пакетът съдържа план, backlog и начални GitHub настройки. Игровата реализация започва задача по задача след прегледа им; тук няма завършено мобилно приложение.

[38 задачи в GitHub](https://github.com/georgi-cole/crystal-path-infinity/issues) са създадени с критерии за приемане, приоритети, области и зависимости. Всички са в Backlog. Започваме с [CPI-001 — правила и продуктови решения](https://github.com/georgi-cole/crystal-path-infinity/issues/1), след което минаваме към техническия spike. Реално приложените и оставащите административни настройки са описани в [статуса на хранилището](docs/REPOSITORY_SETUP.md).

## Първа версия

- Кристалният мост, Stability Points, подсказките, mystery плочките и съществуващата визуална атмосфера.
- Един човек играе собствен опит; асинхронно съревнование с реални хора чрез Top 100 за света, континент и държава.
- Профил с потребителско име, възраст и избрана държава; възрастта е непублична.
- До 10 успешно спечелени рекламни продължавания за един опит. Десетата награда продължава играта; следващата смърт е окончателна.
- React, TypeScript и Capacitor; самостоятелен backend за профили, проверени опити, класации и рекламни награди.

## Проверка на пакета

Python 3.11+ е достатъчен; не се инсталират зависимости на играта.

```bash
python3 scripts/validate_plan.py
python3 scripts/bootstrap_github.py
```

Втората команда по подразбиране показва планираните GitHub операции без изпълнение. Реално създаване: `--apply` след автентикация с GitHub CLI. Прочети документа за настройките.
