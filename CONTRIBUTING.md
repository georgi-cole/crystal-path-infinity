# Работа по задачите

Един branch и PR за конкретна задача с проверими критерии. Първо преглеждаме CPI-001, след това мобилната съвместимост в CPI-002.

- PR обяснява проблема, промененото поведение, проверките и ограниченията.
- Не променяме bbmobilenew-source като страничен ефект.
- Правилата имат версия; несъвместими резултати не се смесват.
- Mock реклами и произволни клиентски scores не са официални награди/рекорди.
- Тайни, signing материали, service-role ключове и лични данни не влизат в git.
- Проверка сега: `python3 scripts/validate_plan.py` и `python3 -m unittest discover -s scripts -p 'test_*.py'`.
- CPI-004 добавя истинските typecheck/lint/core/API/build gates след scaffold-а.

Done означава изпълнени критерии и демо или възпроизводима проверка. Началният CI проверява планирането, не работещо мобилно приложение.
